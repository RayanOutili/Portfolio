# Portfolio

Portfolio personnel de Rayan Outili, en ligne sur [rayan-outili.fr](https://rayan-outili.fr).

Développé en React et TailwindCSS.

## Lancer en local

```bash
npm install
npm start
```

## Déployer

```bash
npm run deploy
```
